# 正则表达式与有限自动机：现场演示

课题五汇报配套代码 ——《正则表达式与有限自动机：从数学理论到 grep 命令》

本仓库用三段 Python 代码，现场演示论文中讲到的三个核心概念。

## 运行环境

- Python 3.10 及以上
- 无第三方依赖（只用标准库 `re` 和 `time`）

## 运行方法

```bash
python demo_regex.py
```

## 三段演示对应论文内容

| 演示 | 对应概念 | 对应 PPT 页 |
|---|---|---|
| 演示1 | 正则表达式：用一行符号描述文字特征 | 第 4 页 |
| 演示2 | 有限自动机：状态 A→B→C，读一个字符跳一次状态 | 第 5 页 |
| 演示3 | 灾难性回溯：输入每多 2 个字符，耗时翻 4 倍（指数级） | 第 10 页 |
